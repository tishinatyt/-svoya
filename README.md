# СВОЯ — жіночий клуб

Вебпроєкт жіночого клубу «СВОЯ».

## Концепція
Живе жіноче ком'юніті: знайомства, зустрічі, кола за інтересами, beauty, бізнес, допомога та події.

## Поточний стан
- адаптивна головна сторінка;
- фотострічка учасниць;
- блоки зустрічей та напрямів клубу;
- CTA на створення профілю / вступ до клубу;
- підготовлена структура під подальше підключення авторизації, бази даних, чатів і push-сповіщень.

## Запуск локально
Відкрийте `index.html` у браузері або запустіть будь-який статичний HTTP-сервер.

Наприклад:
```bash
python -m http.server 8080
```

Після цього відкрийте http://localhost:8080

## Структура
- `index.html` — розмітка
- `styles.css` — стилі та адаптив
- `app.js` — інтерактив і фотострічка
