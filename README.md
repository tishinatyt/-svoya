# СВОЯ — жіночий клуб

Робочий сайт: https://tishinatyt.github.io/-svoya/

Клуб: https://tishinatyt.github.io/-svoya/club/

Цей репозиторій містить оригінальний інтерфейс та функції СВОЯ з опублікованої версії 8 сайту https://svoya-women-club.dr12071980.chatgpt.site/, адаптовані до GitHub Pages. Джерело перенесення: commit `faea30490fce12d288cd0dbc60c3e8b4b4f239df`.

## Структура

- `src/site/page.tsx` — повна стартова сторінка з оригінальними фото, блоками й анімаціями.
- `src/site/portrait-strip.tsx` — стрічка з 50 ілюстративних портретів.
- `src/site/club/club.tsx` — стрічка, події, свої кола, б’юті, бізнес, допомога, профіль, заявки та чати.
- `src/site/club/profile-photos.tsx` — фото профілю, вибір аватара, галерея до 10 фото.
- `src/site/club/notifications.tsx` — сповіщення та керування push на пристрої.
- `src/lib/club-db.ts` — чинний клієнт Supabase з публічним ключем та окремою сесією СВОЯ.
- `src/lib/site-path.ts` — адреси сторінок і ресурсів з урахуванням `/-svoya/`.
- `scripts/build-pages.mjs` — пряма сторінка `/club/`, manifest і fallback для GitHub Pages.
- `supabase/functions/svoya-push/index.ts` — чинна функція повідомлень, що підтримує обидва домени.
- `docs/original-db/` — опис та SQL оригінальної бази СВОЯ для довідки.

Розділи платформи відкриваються параметром `section`: `feed`, `event`, `circle`, `beauty`, `business`, `help`, `profile`. Картка публікації відкривається параметром `entry`. Форми, заявки та чат працюють усередині платформи, як в оригіналі.

Код попередньої спроби перенесення залишено в історії та старих каталогах `src/pages`, `src/contexts` тощо. Він не підключений до робочого застосунку. Міграції попередньої спроби **не потрібно запускати** для цього перенесення: застосунок використовує вже налаштовані оригінальні таблиці `svoya_*`.

## Запуск і публікація

Потрібен Node.js 22.13 або новіший.

```bash
npm ci
npm run dev
npm run test:paths
npm run build
```

Локальна адреса містить префікс `/-svoya/`, щоб перевіряти ті самі шляхи, що й на GitHub Pages. Для іншого префікса задайте `VITE_BASE_PATH` під час запуску/збірки.

GitHub Actions публікує `dist` після змін у `main`. У Settings → Pages джерело має бути GitHub Actions.

## Поточні можливості оригіналу

Публічний перегляд каталогу; швидкий профіль із фото; вхід наявним email/паролем; створення публікацій; заявки й підтвердження участі; чат для підтверджених учасниць; приватні запити на послуги; фото; історія сповіщень і push за згодою користувачки.

Шість карток позначено як приклади для натхнення. Реальні публікації беруться з бази. Оплати в оригіналі не підключені. Швидкий профіль залежить від сесії браузера: очищення даних або вихід може втратити доступ до нього. Сесії старого домену не переносяться між доменами автоматично. Отримання системного push потрібно перевірити на пристрої після надання дозволу.

Репозиторій `tishinatyt/porooch` не є ціллю цієї роботи та не змінюється.
