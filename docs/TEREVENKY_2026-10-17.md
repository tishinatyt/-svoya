Розділ `/club/?section=lounge` з'являється в бічному та мобільному меню. Це один чат для всіх міст. Читання й надсилання доступні учасницям зі схваленою анкетою та фото. Є імена, аватари, перехід до профілю, час повідомлення, перенесення рядка через Shift+Enter, автоматичне оновлення кожні 5 секунд та повернення до нових повідомлень. Повторне надсилання після неоднозначної мережевої помилки використовує той самий UUID. Текст зберігається до підтвердження сервера. Авторка може видалити власне повідомлення, адміністраторка — повідомлення доступної їй переписки. Блокування між учасницями діє й у цьому чаті.

## Межі зміни бази

Єдина міграція: `supabase-svoya/supabase/migrations/20261017160438_svoya_lounge_chat.sql`.

Вона додає лише `public.svoya_lounge_messages`, два індекси, три RLS-політики та обмежені grants. Використовує чинні `svoya_private.is_active`, `blocked`, `owner_visible`, `is_admin`. Читати/писати можуть тільки активні учасниці; відправниця має відповідати `auth.uid()`. Час задає сервер. Гості, анкети на перевірці, призупинені профілі не мають доступу. Максимум 2000 символів; порожні та суто пробільні повідомлення заборонені. Редагування повідомлень не надано.

Чинні таблиці, функції, чати зустрічей і об'єкти PORUCH не змінено. Перед застосуванням перевірено відсутність нової таблиці та відповідність чотирьох допоміжних функцій локальним. Після застосування підтверджено RLS, три політики, індекси та grants: гість не читає чат, учасниця не може підмінити час або редагувати повідомлення. Нових тестових користувачів на production не створювали.

## Перевірки

Пройдені локально: `npm test` (28 тестів), `npm run test:db`, `npm run typecheck`, `npm run build`.

Нові SQL-сценарії перевіряють членство, відсутність доступу гостя, підробку автора/часу/метаданих, блокування в обидва боки, призупинення, видалення, довжину й повторний UUID. Нові React-тести перевіряють відображення тексту без HTML, збереження чернетки, безпечний повтор після втрати відповіді, очищення повідомлень і зупинку запитів після виходу/втрати членства.

Браузерна перевірка `npm run test:lounge:browser` пройшла на desktop/mobile в GitHub Actions: відправка, меню, відсутність горизонтального скролу та видимість поля над нижнім меню. Вона використовує ізольовані відповіді API та тестову сесію, зовнішню мережу заблоковано; це не перевірка доставки production-повідомлень. Знімки й результати — в артефакті `svoya-lounge-preview`.

Повна ізольована перевірка підтвердила Auth, реєстрацію й PostgREST. Виявлений старий браузерний сценарій модерації оновлено під чинне мобільне меню: він відкриває «Меню», переходить до «Модерації» й перевіряє відсутність цього пункту для звичайної учасниці. Гостьовий обхід розділів доповнено `lounge`.
