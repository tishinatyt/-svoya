## Remaining external setup

- The host-root `https://tishinatyt.github.io/robots.txt` returns 404. A file at `/-svoya/robots.txt` is not the host's robots file. This repository cannot publish at the host root; the project copy documents the distinction. Page-level indexing instructions work without a root robots file. Do not block `/club/` in robots: crawlers must read its `noindex` tag.
- Submit `https://tishinatyt.github.io/-svoya/sitemap.xml` to the verified `https://tishinatyt.github.io/-svoya/` Search Console property, then inspect the landing URL. GSC Wizard refused reads because its trial/subscription is inactive, so no search performance or indexing status was available and no submission was made.
- An owned domain would allow root robots and an independent site identity; it needs the owner's domain choice and DNS access. WebSite markup in a project subdirectory does not guarantee a separate Google site name.
- Do not claim indexing, rich results, rankings or Core Web Vitals from code checks. Search engines decide indexing after crawling; field performance requires actual data.
